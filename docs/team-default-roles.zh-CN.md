# 团队默认角色

团队新建、详情、列表和修改接口支持 `defaultRoleIds`，最多 64 个同部署角色。
旧客户端可省略此字段。PATCH 省略时保留原值，传 `[]` 清空默认角色。

有效角色为用户直接分配角色与所属启用团队默认角色的并集，仅启用角色生效。
修改默认角色对现有与新加入成员均生效；离开或禁用团队会撤销该来源的继承，
不会删除用户单独分配的角色。不沿父团队继承，也不会设置用户的超级管理员标记。

管理 API 鉴权、当前身份与会话角色、模型／技能／凭证授权、角色事件、数据范围及
网关主体快照统一使用有效角色。用户管理 `roleIds` 仍表示直接分配，避免编辑用户
时将继承角色误存为永久授权。已签发的模型 JWT 按既有短有效期过期，新令牌读取
当前角色。

配置默认角色需要现有团队编辑权限，并遵循直接分配角色的委派授权检查：不能授予
内置角色或自己不持有的权限。加入团队和重新启用团队也检查其默认角色。
数据库外键限制同部署关联；仍被团队默认配置引用的角色不能删除。
